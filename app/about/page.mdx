# About Celestia documentation

Celestia documentation provides guides for understanding the network, building
integrations, and operating nodes. Start with the
[data availability introduction](/learn/celestia-101/data-availability) for the
network's role, the [developer portal](/developers) for APIs and clients, or the
[node operator overview](/operate/getting-started/overview) for deployment guidance.

The documentation source is public in the
[Celestia docs repository](https://github.com/celestiaorg/docs). Each page's edit
link leads to its source so contributors can propose corrections. When reporting
a technical issue, include the page URL and relevant software version so
maintainers can distinguish documentation errors from version differences.

For information about the teams behind Celestia, visit
[About Celestia](https://celestia.org/about/). For support channels, documentation
feedback, and private security reporting, use the [contact page](/contact).
Agents can discover the same documentation through [llms.txt](/llms.txt), without
relying on browser navigation.
