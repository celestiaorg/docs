# Node API

The Celestia Node API is the collection of RPC methods that can be used to
interact with the services provided by Celestia data availability nodes.
Node API uses auth tokens to control access to this API.

## Machine-readable API specifications

The node API uses JSON-RPC, described by the versioned OpenRPC specifications
linked in the API explorer below.

For the separate celestia-app HTTP REST API, download the
[OpenAPI specification (Swagger 2.0)](/openapi.json) or use the
[upstream Swagger UI](https://celestiaorg.github.io/celestia-app/swagger/).
This is the upstream v10 gRPC-gateway contract, not the node JSON-RPC API or an
API hosted by this documentation site. Configure your client's base URL for your
celestia-app REST provider; the upstream specification does not set a host.
Provider and software versions determine which endpoints are available.

The file follows this [upstream snapshot](https://github.com/celestiaorg/celestia-app/blob/3dd6e22d076ac2131156c98f20c1fda7df195d9c/swagger/swagger.json).
Only duplicate operation IDs are made unique; endpoints and schemas are unchanged.

## Fibre

The Mainnet Beta `{{apiVersions['mainnet']}}` and Mocha `{{apiVersions['mocha']}}`
specifications include the Fibre API.
The [Mocha Fibre walkthrough](/build/post-retrieve-blob/fibre) covers node setup,
escrow funding, submission and retrieval, including tested request encodings
and the JSON-RPC size limit.

Both specifications also include `blob.SubscribeFromStartHeight`, which
replays blobs for a namespace from a start height, then streams new blobs.

## celestia-node v0.31.3 breaking changes

Starting with celestia-node v0.31.3:

- The `fraud` RPC namespace was removed. Calls to `fraud.Get` and
  `fraud.Subscribe` are no longer supported.
- The `type` field returned by `node.Info` is a string such as `"Bridge"` or
  `"Light"` instead of an integer.
- RPC request bodies are limited to 16 MiB. Larger requests are rejected.
- In the Go API, `blob.Commitment.String()` returns a hexadecimal string
  instead of raw bytes. This does not change the JSON encoding of commitment
  fields returned by RPC methods.

See the [celestia-node v0.31.3 release notes](https://github.com/celestiaorg/celestia-node/releases/tag/v0.31.3)
for the complete list of changes.
