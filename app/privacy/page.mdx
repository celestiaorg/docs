# Celestia privacy information

Read the [published Celestia privacy policy](https://celestia.org/privacy/) for
its scope, the information it covers, and the contact instructions for privacy
questions. This documentation page points to that policy; it does not replace
or amend it. Consult the published policy directly for its current wording and
revision date.

Documentation links can take you to separately operated services, including RPC
providers, source repositories, and community platforms. Review the destination's
privacy information before providing account details or credentials. The
[developer portal](/developers) identifies the difference between this public
documentation site and the node endpoints used by applications.

When reporting a documentation problem, share only the information needed to
reproduce it. Public issues and discussions can be read by others. Remove API
keys, authentication tokens, private keys, and personal information from logs
and screenshots before posting them. Use the [contact page](/contact) to find
the appropriate channel, including private security reporting. The
[Celestia terms of service](https://celestia.org/tos/) are available separately.
